# 🔴🔴 喋り方の正典（2026-09-04 EugeneがOKを出した型・ここが核心）

**「めちゃめちゃいい」と言われた157秒版の作り方。以後どんな動画でもこの型で作る。**
実物＝`~/Desktop/ニャクア_157秒_日本語吹替.mp4`／台本＝同名のCSV。

## 1. 演出は audio tags で指定する（速度いじりやない）
ブロックの頭に角カッコで置く。**声には出ん**（実測で確認済み）。

| タグ | どこで使う |
|---|---|
| `[calm]` | 淡々と説明する所 |
| `[thoughtful]` | 「でも…」と切り返す所 |
| `[concerned]` | 問題が深まる所 |
| `[serious]` | 告発・突きつける所 |
| `[worried]` | いちばん深刻な所 |
| `[warm]` | 解決を差し出す所・商品が出る所 |
| `[confident]` | 仕組みを言い切る所 |
| `[reassuring]` | 保証・CTA |

## 2. stability は 0.5 固定
🔴 **0.3に下げたらアカン。** 表現力は上がるが**発音が壊れる**（「よごれた」→「いえがれた」・数字が転ぶ）。実測済み。**発音が先。**

## 3. 🔴 速度は 1.00 以下だけ。押しは「音量」で作る
**速度を上げると促音（小さい「っ」）の詰まりが縮んで消える**（1.08倍で−7%・1.15倍で−13%）。

| role | 速さ | 音量 | どこで使う |
|---|---|---|---|
| normal | 1.00 | 0 | 説明（既定） |
| push | **1.00** | +0.8 | 深刻化・追い込み（音量だけで押す） |
| hook | **1.00** | +2.0 | 畳みかける所（音量だけで押す） |
| bright | **1.00** | +0.4 | 若い人の証言（音量だけで明るく） |
| drop | 0.95 | −0.2 | 落とし |
| calm | 0.95 | −0.2 | 年配の人の証言・落ち着いた所 |
| accuse | 0.92 | −0.8 | 告発（いちばん遅い） |
| soft | 0.90 | 0 | 猫・子ども役。ゆっくり柔らかく |

🔴 **遅くする役は「枠に余裕があるブロックだけ」に当てる。**遅くすると尺が伸びる。
🔴 起伏はナレーターだけやない。猫も証言も全部 normal のままにせん。

## 4. 🔴 0.16秒未満の無音は絶対に触らん
促音（っ）は**0.08〜0.15秒の無音の詰まり**があって初めて聞こえる。
昔は0.08秒以上の無音を全部「息継ぎ」として削っとった＝**「っ」を殺しとった。**

→ `MIN_TOUCH = 0.16` は `~/bin/_koe.py` の1か所だけ（`ma.py`・`muon.py`・`eltts.py` は全部ここを読む。2026-10-02 作り直しで1か所にした）。それ未満は語の中の音とみなして触らん。
（0.14まで下げると息継ぎの割合は上がるが話速の幅が割れる。**0.14 だと⑥が割れるので 0.16 にする。**実測済み）

## 5. 10〜20秒の「話のまとまり」で生成する
1文ずつ別々に作ったらアカン。文と文の隙間が中央値1.00秒・最大3.72秒になった実測あり。
まとまりで続けて読ませて、中の息継ぎは機械に任せる。

## 6. 🔴 ブロックは「次の出番の0.25秒前まで」で切る
```
許容 = min(自分の終わり, 次の開始 − 0.25) − 自分の開始
```
+0.20秒の許容で作ると**ズレが累積して声が映像から最大1.2秒遅れる**（実測）。
声優の吹き替えは**ブレスの位置を映像に合わせる**のが基本。**出番のズレ0.00秒を狙う。**

## 7. 🔴 振り直しは「長さ＋誤読」の両方で採る
長さだけで最短の回を採ると、**発音が転けた回を採ってまう**（「サンマリオン」が復活した実測）。
`scripts/reroll.py` が誤読リストで弾いてから長さで選ぶ。最大5回。

## 8. 枠にはみ出たら「言い回しを締める」。速度は上げん

## 9. 間は「…」（三点リーダ）で作る
v3はSSMLの break に非対応。「、」＝短い間／「。」＝長い間／「…」＝重みのある間。

## 10. キャラが喋る所は日本語ネイティブ声で柔らかく
ナレーションも猫・子ども役もElevenLabs V4に統一する。Sarah・「元気な女性」等の既存配役はV4での互換性を確認して使い、
話し言葉（「ねえ…」「〜なんだ」）にする。声が変わる所は間が空いてOK（話者交代）。

## 11. 転ぶ語は言い換える（下の表）。辞書に入れる前に必ず実測する

## 12. 検算は9項目。全部通してから見せる

## 言葉の鉄則

### 🔴🔴 ①元動画の主張を、訳す前に「うちの商品にあるか」1つずつ照合する（2026-09-08制定）
**元動画は他社の広告や。うちの商品に無い機能・数字が混ざっとる。訳したら嘘になる。**

🔴 実測（2026-09-08）：同じKittySpoutの広告2本が**互いに食い違っとった**。
　67秒版=「three-layer」／85秒版=「dual-layer」。**どっちも間違いで、実物は4つの層。**
　照合せずに訳して、67秒版を「みっつの層」「医療用ステンレス」で一度納品してしまった（後で差し替え）。

**やり方**：台本を書く前に、英語の主張を全部書き出して、うちの商品ページと突き合わせる。
```
ニャクアの正典 = ~/fountain-canon/advertorial/page.advertorial.liquid
```
| 判定 | 処理 |
|---|---|
| うちにも有る | 使う。ただし**販売元の公表値は「販売元によると〜そうです」**と出所を付ける |
| うちに無い／数字が違う | **実物の数字に直す**（例: dual→よっつの層） |
| 他社の数字・No.1・◯万人 | **落とす**。穴が空いたら**うちの本当の仕様で埋める**（無音を残さん） |
| 出典の無い統計（3匹に1匹が腎臓病 等） | **落とす** |
| 病気を「防ぐ／心配が消える」 | **言い換える**（「毎日ちゃんと飲める」） | <!-- 掘った: 台詞の例文。`ちゃんと` はコピーの語で測る物ではない -->
| 割引（50%オフ 等） | **落とす**（景表法）。※画面の英語テロップは触らんので残る＝要確認事項として報告する |

- 商品名は**うちの名前**に。画面の字も読みも**カタカナ**（例：ニャクア）
- 他社の数字（21万人・獣医推奨等）は使わん → 「そこで生まれたのが、○○です」
- 病気を「防ぐ／止める」と言わん → 「毎日ちゃんと飲める」「飲む量が体を守る」に <!-- 掘った: 台詞の例文。`ちゃんと` はコピーの語で測る物ではない -->
- 割引の表示は入れん（景表法）
- アラビア数字は**漢数字かかな**に（1日2回→一日二回）。テロップを作る時だけ算用数字
- 言いさしで終わらん。「〜ので。」やのうて言い切る

# 工程

### ⓪ 🔴 声を選んでもらう（作り始める前に必ず）
**勝手に声を決めて進めたらアカン。** 動画を渡された時点でこの6択を見せる。

| # | 声 | 性格 |
|---|---|---|
| 1 | **Hatake Kohei**（男） | 中年・落ち着き・低め |
| 2 | **Daisuke**（男） | 若め・関東・声を張る |
| 3 | **Mitsuwo**（男） | 中年・広告向き・いちばん抑揚がある |
| 4 | **Sarah**（女） | 若め・標準・ナレーション |
| 5 | **Kei**（女） | 中年・落ち着き |
| 6 | **Sakura**（女） | 若め・会話向き |

**女性が単体で喋る動画なら、先に「Sarah でいいですか？」と聞く。**（Sarahが正典）
2人以上の話者がおる動画（②で分かる）は、話者ごとに誰を当てるかも一緒に確認する。
voice_id は `~/bin/voices.json`（名前で書けば id に直る。6本＋Miki.T＋Fish「元気な女性」）。

### ① 文字起こし
```
scripts/01_transcribe.sh <元動画.mp4> <作業フォルダ>
```

### ② 話者を全員洗い出す（🔴飛ばすと事故る）
**本人が言うてない話者が混じっとることがある。**（KittySpoutは「猫と男」と聞いて実際は5人）
F0の目安＝男性100〜140Hz／女性190〜230Hz／猫役・子ども役260Hz〜。
⚠️ 自己相関は倍音を拾うことがある。**推定したF0の半分の周波数にスペクトルの山が無いかも確かめる。**
映像も必ず見る（コンタクトシート）。顔出しの証言が混じっとったら年代ごとに別の声を当てる。

### ③ 台本を書く（🔴まとまり単位で）
CSV＝`no,start,end,who,role,ja`
- **who** … cat / w1 / man …（`voices.json` で voice_id に対応づける）
- **role** … 上の表から。**速度1.00超は使わん**
- **ja** … 頭に audio tag。文字数の目安＝**枠の秒 × 5.5字**（間詰め後に縮むので少し多めに書く）

### ④ 声を作る
```
python3 ~/bin/eltts.py <作業フォルダ> <台本.csv> --stability 0.5 [--who w1] [--only 3,7] [--置く]
```
ElevenLabs＝**eleven_v4 ＋ 発音辞書 `jp-fukikae`（V4対応は実装担当の確認待ち）**。who→声は `<作業フォルダ>/voices.json`（例 `{"w1": "Sarah", "cat": "v4:元気な女性"}`）。
出る物＝`seg/NN.mp3`（無音化→間合わせ→role の音量 済み）と `seg/NN_raw.mp3`。枠からのはみ出しを1行ずつ出す。
`--置く` を付けると ⑤ の流し置きまでやって `narration.mp3` を書く（尺は `duration.txt`）。
猫・子どもの声は voices.json に `v4:` を付けて書く（`v4:元気な女性`・`v4:Sakura`）。ElevenLabs の `eleven_v4` で読む。Fish Audio は使わない（2026-10-02 本人）。
全文を1回で読ませる時（VSL）は `eltts.py --全文 <台本.txt> --voice <名前> --out <声.wav>`（読みの検査つき）。

### 🔴🔴 ④.4 息を消す（2026-09-09 Eugene指示・これが標準）
**「なんか変な音が入ってる。BGMを残そうとしてるみたいに聞こえる。完全に消してほしい」**
```
python3 ~/bin/muon.py 入力.mp3 出力.mp3 [--report]      # 間だけ音量ゼロ。長さは1ミリも変えん＝促音は無傷
```
🔴 実測（2026-09-09）：納品物の「無音のはずの間」133か所のうち **46.8%に−41dBまでの音**が入っとった。
　内訳＝TTS自身の息が48.4%ぶん、そこへ `iki.py` が足して78.4%まで増やしとった。
　**元動画の音ではない**（相関 −0.002＝ゼロ）。**足しとったのはこっち。**
→ `muon.py` を通すと 間の中央値 **−50.7dB → −140.0dB（完全な無音）**・聞こえる音 46.8%→4.6%。

🔴 **次の声の頭の前0.12秒は消さん**（`muon.py` の `LEAD`）。ふ・へ・ぺ の出だしは弱くて無音の線の下に沈む。12ミリしか残さんかったら「ふっと→ぐっと」「ペア→部屋」に化けた（2026-10-02 実測・同じ音の聞き取りで比べた）。

**工程の順番が大事**：`muon.py`（無音化）→ `ma.py --match`（間の分布合わせ）。
逆にすると無音化で隣の間がつながって ④90%点が0.37秒まで伸びる（実測）。

⚠️ **代償**：②息継ぎの割合（47%前後）と④90%点が落ちる。**それでも音がきれいな方を取る**（Eugene判断）。

### ④.5 息を入れる（🔴 2026-09-09に廃止。下は記録として残す。`iki.py` と息の素材 `breath/` は消えていて、作り直していない）
```
iki.py 入力.mp3 出力.mp3 --gain 1
```
素材＝`breath/`（プロのナレーターから切り出した息91個）。間に息の音を置く。

**⑨のやり方**：台本の「っ」1個ずつに対し、**直前のかな1字＋っ＋直後1字**を最小単位として聞き取り結果を探す。

⚠️ **whisperは数字を算用数字で書く**（みっつ→「3つ」・三週間→「3週間」）。照合の前にかなに戻す。

⚠️ **②が 47〜50% に落ちるのは「っ」を守る代償**（0.16秒未満を詰めんから）。

## 🔴 納品前の最後の一手：連番の暴走チェック（2026-09-04追加）
書き出しが終わったら、**出力先に同名の連番ファイルが増えてへんか必ず数える**。

```bash
ls "<出力先>" | sed -E 's/_[0-9]+\.mp4$//' | sort | uniq -c | sort -rn | head -3
```

同じ名前が **2個以上** 出たら、そこで止めて原因を報告する。
