# 硬貨の画像（値段の段の縦長の値段画像で使う）

読む人: `値段を組む.py` を直す人。
読む時: 硬貨の見た目を替える時。
読まなくていい条件: 記事を作るだけの時（道具が自動で使う）。

本物の日本の硬貨の見た目（2026-10-12 本人「おもちゃの丸は安く見える。実際のお金のデザインに」）。`元/` は ChatGPT（MCP chatgpt-image）で作った写真、`<額>.png` は丸く切り抜いた 240×240 の透過 PNG（5円・50円は穴も透過）。道具は額ごとに本物の直径の比（1円20mm・5円22mm・10円23.5mm・50円21mm・100円22.6mm・500円26.5mm）で並べる。
