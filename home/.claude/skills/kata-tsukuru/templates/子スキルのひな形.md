# 3. 実行手順（毎回この順）

1. **参考を1本選ぶ**: 広告の段の並びに一番近い参考を `refs/` から選ぶ（見た目でなく段の並び）。理由を1行
2. **段に割る・移植表**: 参考の段を上から全部、左に参考・右に日本語、段の仕事・心理の効果・広告からの受け渡し・出どころを1段ずつ。段ごとに「ビジュアル」（画像の中身・人と物・画像の中の文字・大きさと置き場。スマホの幅で撮った画面を見て書く）と「コピー」（見出し・本文・強調・注記）を分けて書き、うちの物も両方を1段ずつ埋める
3. **必ず入れる物を足す**: `~/Documents/Obsidian Vault/ec/構造/型/_必ず入れる物.md` の一覧を、足し方の決まり（場所・見た目・文・印）どおりに移植表へ足す。値段の段は `python3 ~/.claude/skills/kata-tsukuru/scripts/値段の段を組む.py <入力.json>` の断片を、この型の値段を出す段に貼る（ここちドライの見せ方とエフェクト・色と字はブランド。`記事の仕上がり検査.py` の10）
3b. **組む**: <道具>で出来た物を作る。値段・保証は本番の店から
4. **画像**: 参考の同じ場所の画像を ChatGPT の MCP（`mcp__chatgpt-image__generate_image`）に添付し、人物を日本人・商品を自社に替える
5. **機械の検査**: <検査の道具> が終了コード0になるまで3に戻る
6. **別の AI の審査**: 新しい文脈の Opus のサブエージェント（`model: "opus"`・`run_in_background: false`）に参考・出来た物・最終確認を渡し、1行目 PASS か `FAIL: <理由>` を `審査_<回>.md` に
7. **最終確認**: 上の箱を全部埋める。×はその箱の手順へ戻る
