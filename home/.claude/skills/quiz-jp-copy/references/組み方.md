# 組み方（手順3〜5の細かい決まり）

読む人: quiz-jp-copy で index.html と画像を作る Claude。
読む時: 手順3〜5に入る時。
読まなくていい条件: 文言を1か所だけ直す時。

決まりの元（なぜそうするか）は `~/Claude Code/kata-tsukuru/runs/quiz-jp/直しの記録.md` と `見本/`。ここには「どうするか」だけを書く。

## 手順2 オファーの表（移植表の頭に1回だけ）

値段の数字・割引の理由・期限・セットの中身・おまけ・保証を、表で1回だけ決める。ページの中の値段の画像・札・ボタン・申込のページは、全部この表の言葉だけを使う（参考の「秋の大セール」のような別の理由を写さない）。割引の理由はアンケート型なら「3問に答えた方だけ」の1つ、期限は1つ（例: 本日受付終了まで）。2026-10-10 2本目で、値段・条件・中身・理由と期限を画像ごとに作り、読み手の目が4回とも別の食い違いを挙げた。

## 手順3 必ず入れる物を足す

| 物 | 置く段 | 形 |
|---|---|---|
| 最悪の結末 | 頭の絵のすぐ下 | ✅で2〜3行。頭の絵が縦長の時は段の幅を390px・1行25字以内にして、1280×800 の最初の画面にも収める |
| 値段の見せ方 | 問いの前の値段の札の段と、お礼の後の申込の段 | 問いの前: 1日あたりの文 → 今の対策（例: パッド代）と比べる文 → 値段の札の画像。札の値段は「この下の3問に答えると」と答えることを条件にして見せる（参考の BODY-VO「この下にある3問に答えると＼衝撃の50%OFF!!／」と同じ）。お礼の後: 「答えた方だけ」の同じ値段 → 縦長の値段画像。前後で値段の数字と条件を食い違わせない。問いの前の段（`data-tasu="2"`）は `~/.claude/skills/kata-tsukuru/scripts/値段の段を組む.py` の断片で組み、札の「答えると」の条件は入力の「札」「前振り」に書く（2026-10-11 本人）。前は `--出す 札だけ`（縦長の値段画像を出さない）・お礼の後は `--出す 全部`（同じ入力で2回組み、後の段は「外枠の属性」に id・hidden を残す） |

- 型.md の分岐で足す段（例: バレない配送）は、選んだ参考にその段がある時だけ足す
- 足した段の枠に `data-tasu="<番号>"`

## 手順4 組む（印）

| 印 | 付ける所 | 使う道具 |
|---|---|---|
| `data-dan="<型の段の番号>"` | 段ごとの枠 | 型の検査（A2 型の16段） |
| `data-q="1"`〜 | 問い1問ずつの枠。見出しは `Q1.` の形 | 型の検査（問いの数）・幅の検査（押した後の進み） |
| `data-answer` | 答えのボタン。答えた後は外して、選んだ答えの帯に替える | 幅の検査 `--押す 3` |
| `data-cta` | 申込のボタン（お礼の後・本文の中） | 計測 |
| `data-tasu` | 必ず入れる物の段 | 型の検査（T1 T2）・読み手の目の答え合わせ |

- どの答えでも次の問いへ進み、3問目の後にお礼の段を出す（JS は index.html の中）
- 申込ボタンの先も作る: 参考の申込ボタンを押した先（`ac.ad-growth.jp` の中継の先の申込のページ。中継が無い参考は、ボタンの行き先そのもの）を最後の入力の手前まで割り、`申込/index.html` として同じ見た目・同じ動き（残り時間の数え下げ・プランの選択・入力を1つずつ・「あと○問」・次へ）で作る。送信は押させず、最後は「ここで送信」の印で止める。記事の申込ボタン（`data-cta`）の行き先はこのページ
- 見た目は参考に合わせる: 短い行・赤字・黄色の下線・絵文字・画像はスマホの幅いっぱい
- `<meta name="robots" content="noindex">`
- テスト用に決めた数字・人・声は `テスト用に決めた値.md`、商品情報で分からず予測した所は `予測した事.md`（何を・どう予測したか・根拠のファイル）

## 手順5 画像

1. `python3 ~/.claude/skills/quiz-jp-copy/scripts/参考の画像を落とす.py <参考の HTML か URL> <作業フォルダ>/参考の画像/`
2. 参考の同じ段の画像を `mcp__chatgpt-image__generate_image` に添付し、人物を日本人・商品を自社（本番の店の商品画像を添付）に替える。構図と画像の中の字の置き方は参考のまま
3. 画像の中の文字は、同じ文を `alt` にも書く
4. 細長い画像（縦÷横 0.4未満・2.5超）は作らない。縦長の値段画像は、作った後に縦を切って 幅÷高さ 0.70 にする。縦長の値段画像に載せるのは「1日あたりの値段」と「答えた方だけの値段」だけで、セットの中身・おまけの説明は載せない（中身の説明は記事の中の1か所だけ。2026-10-10 2本目でくり返しになり、読み手の目が切れとして挙げた）
5. 値段の札の画像は参考の形のまま、通常の値段に打ち消し線を入れる
6. 生成が `IMAGE_GEN_UNAVAILABLE` で落ちたら、参考の体の図の部分を切り、文字の置き方の部分だけ添付し直す
