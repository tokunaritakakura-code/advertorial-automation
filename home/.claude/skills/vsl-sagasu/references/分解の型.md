## 埋め方

| 節 | 自社の広告 | GetHookd の広告 |
|---|---|---|
| 0〜3秒の画 | `permalink_url` から落として `ffmpeg` で 0/1/3 秒に切る | `download_url` の mp4 を落として同じように切る（`_勝ち一覧.md` の行に入っている） |
| 原文 | Vault に台本があればそれが正本（`ec/<商品>/05 VSL/`）。無ければ `whisper-cli` で起こす | `whisper-cli` で起こす（MCPの文字起こしは使わない） |
| 実測 | Meta の `video_p25_watched_actions` `video_p100_watched_actions` `impressions` | 点と配信日数と尺だけ。出稿の数字は見えない |

動画を手元に落とす（自社は台本が無い時だけ。GetHookd は毎回）:

`permalink_url` は `ads_get_ad_videos(video_ids=[<video_id>], fields=["permalink_url","length"])` で取る。
`/reel/<video_id>/` という相対のパスで返るので、頭に `https://www.facebook.com` を付ける。

```bash
W=/tmp/vsl-sagasu && mkdir -p $W && cd $W
# cookie 無しでは落ちない（2026-09-22 実測）。ブラウザのログインを借りる
# 自社（Meta）
yt-dlp --socket-timeout 20 --cookies-from-browser chrome -o ad.mp4 "https://www.facebook.com/reel/<video_id>/"
# GetHookd の download_url は curl では落ちない（ログインが要る。返るのはサインインのHTML。
# 2026-09-22 実測）。ブラウザに落とさせて ~/Downloads から拾う
dia nav "<download_url>" --tab gethookd
mv ~/Downloads/<落ちてきた名前>.mp4 ad.mp4
for t in 0 1 3; do ffmpeg -loglevel error -ss $t -i ad.mp4 -frames:v 1 -vf scale=360:-1 h$t.jpg -y; done
# whisper-cli は wav しか読まないので先に変換する
ffmpeg -loglevel error -i ad.mp4 -ar 16000 -ac 1 -c:a pcm_s16le ad.wav -y
whisper-cli -m ~/.cache/whisper/ggml-large-v3-turbo.bin -l ja -f ad.wav   # 秒つきで出る
```

画は `Read` で開いて自分の目で見る。0秒と3秒の2枚で「動き」まで分かる（2026-09-22 実測）。
