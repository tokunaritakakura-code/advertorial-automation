# 3. 実行手順（毎回この順）

0. **型を確かめる**: Vault `ec/構造/型/_VSLから型を選ぶ.md` で、受ける広告の段階が「解決策を知っている」（最初の3行で今ある解決策の名前か種類を出して比べる）かを確かめる。違えばそこに書いた型へ
1. **参考を1本選ぶ**: 上の「参考の選び方」で1本。理由を1行。広告の文と画像の中の字の最後の3行を書き出す
