## 分岐（何で変わるか）

| 変数 | 条件 | どう変わる |
|---|---|---|
| 比べる物の形 | 競合が物（道具・液）なら比較表（01）。飲む物なら「3つの道」（02）か費用の並び（04） | うちは物なので比較表 |
| 選択肢の段 | 値段が $30 以下の消耗品（02 $29.99）だけ「何もしない／薬／これ」の3択を置く | 1万円台のセットなら置かず、費用の並びで代える |
| 動画の面 | 参考に動く物があれば（01 の12.9秒）その面だけ動く物で作る | 無ければ写真 |
| 日本語の記事 | 売る国が日本なら、見た目と字はうちの店（Zen Maru Gothic）、値段の段はここちドライの形（白地・商品の色の枠・打ち消し線→赤の値段・セット3枚のカード・一番人気の札。`_必ず入れる物.md` 2）。最初の画面は 題36字・導入50字・箱90字 以内（2026-10-11 本人） | 英語の黒い箱と長い題は写さない |
| 「Amazon に無い」 | Amazon に同じ形の安い物がある商品（01・02）だけ、偽物の注意と直販の理由を1段 | 無ければ入れない |
