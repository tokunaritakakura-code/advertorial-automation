## 取り方

- 出どころ: GetHookd（Claude 用のブラウザ `dia-agent` の自分のタブで `https://app.gethookd.ai/ads/<ID>` を開き、本文・題・配信日数を `dia-agent read` で、画像を `ads_media` の URL から取った）。2026-10-11 20:30〜21:00
- 選び方: 型さがしの広告100本の表（`runs/_さがし/2026-10-11_static_2_広告100本.tsv`）から、refs の8本の記事に飛んでいる static 広告を全部（9本。healthydogreviews は2本）
- 画像と文の写し: `広告/<ID>.jpg`・`広告/<ID>.txt`、9本を並べた1枚 `広告/並べ図.jpg`
- 段階: 9本とも「解決策を知っている」（広告の最初の3行で、今ある解決策（他社のサプリ・おやつ・バッグ・副業）の名前か種類を出して比べる。見分け方は Vault `ec/構造/型/_VSLから型を選ぶ.md`）
- 段の番号: 「この型のどの段で受けるか」は `型.md` の固定の段（段1 題〜段12 申込の先）

## 線（この組み立て → この型）

- 3つの組み立てとも「比べた・順位を付けた・1つだけ」を言い切り、1位の名前を残す。記事はその残した1位を段5〜6で言う。広告が他社の名前を出していれば（3・6・9）、記事も同じ他社の名前の順位を段5に並べる
- 商品の構造・痛みが合えば、この組み立ての広告から別の型（権威の暴露記事）へ飛ばしてもよい。広告4のように医師が隠れた原因を言う物は、権威の暴露記事の段3（隠れた原因）でも受けられる
