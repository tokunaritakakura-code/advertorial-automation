読む人: ranking-copy で1本作る Claude と、この型を直す Claude。

読まなくていい条件: 悩みの名指しから入る広告（問題に気づいている）の記事は権威の暴露記事の型。

static・解決策を知っている・同じ構造 8本で採用（2026-10-11 の型さがし `runs/_さがし/2026-10-11_static_2.md`。広告の棚の勝っている印 score 100・配信 26〜63日。売上は見えないので、勝っているは仮説）。

## 誤差（決められない・効きが分からない）

- 順位の数が5か4か（7本が5、06 は4）。5から始める
- 2位以下に実在の他社の名前を出すか（8本とも出す）。日本の記事で他社の名前を出して低い点を付けるかは本人が決める。テストの記事では他社の商品の種類（「ドラッグストアの吸水ショーツ」の類）で並べ、`予測した事.md` に書く
- 1位の短所を1つ出すか（01 02 04 05 06 08 は「売り切れる」の類を1つ）。出す方から始める
