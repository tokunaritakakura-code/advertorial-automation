読む時: 移植表を書く前・最終確認の F の箱を付ける時。

この型は新しい型ではなく、今ある「リスティクル」（`_VSLから型を選ぶ.md` の芯「理由の列挙」: 題→理由の列挙→値段・オファー→客の声→保証）の、ネイティブ広告（長い文の広告）から飛ぶ時のフォーマット。参考は `refs/01〜03`（Metabolae・Neurivo・PiPi Tea。3本とも Solution Aware＝今ある解決策の名前を出して切る広告から飛ぶ）。線は仮説（売上は見えない。勝っている印＝GetHookd の score 81以上と配信日数）。本人の決め（2026-10-12）: 参考はマスごとに1本。Solution Aware のマスは Metabolae kidney-1、Problem Aware のマスは tubo 5-reasons。

## 固定（3本の参考のうち何本に出たか。3本以上が固定）

| # | 変数 | 値 | 出た参考 |
|---|---|---|---|
| F1 | 段の並び | 題 → 理由の列挙（番号つき）→ 数の証拠 → 商品の紹介 → 客の声 → 値段・オファー（急がせ・保証） → 客の声（芯「理由の列挙」の順。間に 比べる物・使い方 が入ってよい） | 3/3 |

| F3 | 理由の形 | 番号か ✅ の見出し＋短い本文。見出しは「起きる良い事＋その本当の理由」。4〜7個 | 3/3（7・7・4） |

## 分岐（何で変わるか）

| 変数 | 条件 | どう変わる |
|---|---|---|
| 段階 | Solution Aware（参考 Metabolae）なら理由の1つが「今の対策を切る」。Problem Aware（参考 tubo 5-reasons）なら理由は症状の場面から入り、切るのは後ろの理由1つだけ | うちの4本目（Problem Aware の理由の列挙）は tubo を段に割ってから移植表 |
| 理由の対 | 競合が「待て・手術」のような大きい対策なら ❌→✅ の対（02）。安い同種の物なら「本当の理由」の括弧（01）。薬・サプリなら ✅ の箇条書き＋VS の表（03） | うちは安い同種の物（楽天のサポーター）なので 01 の形＋VS の表 |
| 変化の時間表 | 飲む物（03）だけ 1週〜12か月の表 | 道具なら「朝の一歩・立ち仕事の夕方・寝る時」の場面の表で代える |
| 動く物 | 参考に動く物があれば（02 の理由1の10秒）その面だけ | 01 には無い。うちは商品が足を包む面だけ |
| 日本語の記事 | 売る国が日本なら、見た目と字はうちの店（Zen Maru Gothic）、値段の段はここちドライの形（`_必ず入れる物.md` 2）。最初の画面は 題36字・導入50字・箱90字 以内。「1日あたりこんなに安いのに」の文を値段の段に1つ（2026-10-12 本人） | 英語の黒い箱・白地のブログの見た目は写さない |

## 誤差（決められない・効きが分からない）

- 理由の数（4〜7）・本文の長さ（記事 13,000〜26,000字）
- 客の声の本数（3〜9）・% の値
- 色（01 茶、02 白と黒、03 赤）。うちは商品のテーマの色
- タイマーの残り時間（02:59:58 / 07:23）
