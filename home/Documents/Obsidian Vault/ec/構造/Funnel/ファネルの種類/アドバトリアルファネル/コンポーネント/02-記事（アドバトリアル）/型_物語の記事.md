# 記事の型: 物語の記事 — ブロックの詳細

読む人: この型の記事を作る・直す Claude と本人。
読む時: [[05 記事を作る]] の手順3（移植表）・4（入り）・6（ページを組む）で、この型のブロックを作る前。
読まなくていい条件: 別の型の記事を作る時。

この型の役目: 別の人の物語でもう一度
この型へ飛ぶ VSL の形式: 昔の権威（記事あり）｜Calmwise Journal 207日（[[VSLから記事まで_全体の木.canvas]]）
どの型でも同じ決まり（記事の色・文の折り返し・流れる帯・値段の1日あたり）は [[05 記事を作る]] の手順6と10。ここにはこの型だけの決まりを、ブロックごとに書く。新しい決まりをもらったら、そのブロックの「作り方」に足す。

### 言葉の定義
| 言葉 | 意味 |
|---|---|
| 仕事 | そのブロックを読んだ人に起こしたい事（心の動き） |
| 作り方 | そのブロックを作る時に守る順番と中身。本人の直しと審査で増える |
| 確かめ方 | 出来た記事でそれを確かめる最終確認の表の行 |

### 作り方（この枝だけの決まり）

- ページの印: `<body data-format="漫画">` を付ける（`漫画の部品.py` の `page()` が付ける）。`記事の仕上がり検査.py` はこの印で漫画と見分け、「最後まで読んでほしい」の1回を求めない（物語で読ませる形なので入れない。2026-10-11 本人）
- コマの割り方: 画像は全部スマホ幅いっぱいで、縦長 2:3・正方形 1:1・横長 3:2 の3種類だけ。1枚の画像の中を斜めの白い線で2〜4コマに割る。参考の画像1枚＝うちの画像1枚で、番号も同じにする（`m<参考の番号>.jpg`）
- 吹き出しと地の文の分け方: 登場人物のセリフ・効果の字は全部画像の中（縦書き・強調は赤かピンク）。画像の間の地の文は中央寄せで1〜2行ずつ。主人公の心の声は地の文の代わりに、顔の丸アイコンつきの青い吹き出し（`漫画の部品.py` の `fuki`）。後半の大事な一言はピンクの吹き出し（`pfuki`）。段の切れ目はピンクの点3つ（`dots`）
- 必ず入れる物1（最初の画面の最悪の結末の✅）は、広告の調子でなく主人公の心の声で書く（例「＼でも、あの頃の私は知らなかった…／」から✅3行）。広告の調子だと恋の見出しと温度が違って浮く（2026-10-11 読み手の目 1_4 で切れ・中）
- 画像の作り方と指示の型: 参考の同じ番号の画像を添付1、商品が写る時は本物の商品の写真を添付2にして、MCP `chatgpt-image` で描き直す。指示は `漫画の指示.py` の2つの型（m＝漫画のコマ: 同じコマ割り・構図・吹き出しの位置で、人物を日本人に／p＝写真や図: 同じ構図と字の置き方）に、記事ごとの「人物の設定」と「画像に入れる字」を足す。字は一字一句書き、alt にも同じ文を書く。名前・セリフ・コマは直訳で効くならそのまま（由美・ゆり・久保くんも残した）
- 図やグラフを直す時は、前の画像の上に描き足させず、1枚まるごと作り直す（m036 で枠が2重になり審査で3回落ちた）
- 細い帯（縦÷横が 0.4 未満）は細長い画像の検査で落ちるので、縦横を直して置く（`漫画の画像を置く.py --直す`）
- 動く物: 参考で動画だった番号は、中身が動く動画にする。止まった絵をゆっくり寄せた mp4 は使わない（2026-10-11 動きの検査で27本中18本が「寄せただけ」で落ちた）。実写の面は同じ商品を売る店の動画が先、無い面は `動く物を作る.py`（うちの止まった絵から Kling。カメラ固定・文字と商品の形は動かさない）
- 商品が写るコマは、本物の商品の形（帯の形・縫い目・股の作り・色）どおりに描く。添付2は「深めのショーツ」のような言葉でなく、本物の写真（店の front・平置きの写真）にし、帯のV字・斜めの縫い目のような形の点を指示に1つずつ書く。描き終えたら記事・申込・ボタンの画像を `grep -o 'src="[^"]*"'` で全部出し、商品が写る物を全部本物の写真と並べた1枚（`見比べ_商品の形.jpg`）にする（2026-10-11: 言葉だけで描いた写真の帯がまっすぐで審査が2回落ちた。1回目は12枚だけ直して、値段の画像・申込のボタンの11枚が漏れた）
- アンケートと値段のつなぎ: 段14の結末の最後で、友人が「○%OFFで手に入る裏技があるわよ！」と値段の段へ渡す。段15で「お高め→でも今このページだけ」、段16で必ず入れる物2（1日あたり→比べる物→値段の札）、段17でおまけと期限、段18で不安つぶし、段19の「タップするだけ！3問で完了！」から3問、「回答を完了する」で縦長の値段の画像が出て、申込ボタンは手元の `申込/index.html`（チャット型の入力5つ・残り時間の帯・プランの選択・「あと○問」）。段16と「回答を完了する」の後の値段は `~/.claude/skills/kata-tsukuru/scripts/値段の段を組む.py` で組み、前（段16）は `--出す 札だけ`・後は `--出す 全部`（2026-10-11）
- 値段は1枚か5枚セットかを1つに決めて全段でそろえる。前振りの「1日あたり」は、後で出すセットの話とぶつからない数え方にする（「1枚で約100回はける→はいた日の1日あたり約55円」。読み手の目 1_1・1_4 で切れ）
