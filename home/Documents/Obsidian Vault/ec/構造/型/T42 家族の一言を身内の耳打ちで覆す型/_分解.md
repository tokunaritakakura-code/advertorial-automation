## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 前と後の言い切り | 参考の `De 110 libras a "dura" en 3 meses`。語り手の前の姿と3か月後の姿を1文で言い切る。数字か、目に見える姿で言う |
| 信じてもらえない | 参考の `cuando digo que no usé pastillas, no me creen`。皆が思う近道（薬）を使っていないと言うと信じてもらえない、の1文。フックはこの2文で止める |
| 家族の一言 | 参考の `¿Y tú por qué saliste tan plana, mija?`。家族の集まりのたびに、自分だけ違う所を言われる一言。語り手はそれを生まれつきだと信じ込む |
| 耳打ち | 参考の `Un día mi prima me llevó pa'l lado`。身内（いとこ）が語り手を脇に呼び、「誰も分かっていない事」として仕組みを教える。語り手が自分で調べるのではない |
| 地図 | 参考の `se pierde el mapa`。体の中で「行き先を決める物」があり、それが弱ると行き先を失って別の場所へ行く、という仕組みのたとえ |
| 壊れた地図に足す | 参考の `Están tirando calorías a un mapa roto`。試した物は量を足しているだけで、行き先を決める物を直していない、と試した物をまとめて外す |
| あなたの問題じゃない | 参考の `tú no tienes un problema de comida. Tus hormonas solo están guardando mal`。家族の一言（生まれつき）と、見る人が思う原因の両方を外す1文 |
| 生まれつき | 参考の `pura genética`。家族の一言を何度も聞いて、語り手が信じ込んだ原因。6段の「あなたの問題じゃない」で外す |
| しまい方 | 参考の `guardando mal`。体が物を送る先を間違えている事。量が足りないのではない、という意味で使う |
| やめた | 参考の `Dejé de…`。3か月後に、前はしていた我慢やごまかしをしなくなった事を言う短い文の形 |
| 想像して | 参考の `Imagínate…`。11段で見る人を3か月後の朝の場面に置く呼びかけ。3つの姿を続けて言う |
| あなたにも | 参考の `puede ser pa' ti también`。語り手の話を見る人へ渡す1語。11段の終わりに1回だけ言う |
| 暮らしの「やめた」 | 参考の `Dejé de comprar ropa de niña / Dejé de esconderme…`。3か月後の変化を「〜をやめた」「〜と言われない」「〜と言われる」の短い文で5つ並べる。家族の一言の逆も入れる |

## 一行で

**前と後を3か月で言い切り「薬じゃないと言っても信じない」で呼び止める→家族の集まりのたびに自分だけ違う所を言われ、生まれつきだと信じ込み、何でも試した→ある日いとこが脇に呼んで「誰も分かっていない事」→体の中の「地図」（行き先を決める物）が弱ると行き先を失って別の所へ行く→だから試した物は壊れた地図に足しているだけ→あなたの問題じゃない、しまい方を間違えているだけ→だから替えた（商品・中身・行き先が戻る・つらい所なし）→仲間の声と周りの「何かしたの？」→わたしも疑った・お金を捨ててきた・同じ人の声を見て試した→3か月で「やめた／言われない／言われる」を5つ→唯一の後悔→「想像して」朝の姿→保証→本物が欲しいなら下のリンク。**

日を追って変わる（T11・T16・T18・T19）とは、日付の区切りが無く、3か月の後の暮らしを「やめた」で並べる所が違う。仕組みを解き明かす（T07・T08・T13・T23）とは、仕組みを語るのが語り手でなく身内（いとこ）で、家族の一言を覆すための材料として出てくる所が違う。買った本人が語る（T03）とは、家族の集まりの一言→生まれつきと信じ込む→身内の耳打ち→地図の仕組み→「あなたの問題じゃない」→家族の一言が逆になる、の筋が違う。身内の秘密を盗み見て真似る（T25）とは、こっそり見るのでなく身内が自分から教える所、週ごとの変化が無い所が違う。年のせいにされた本人が語る（T24）とは、片づけるのが家族の一言で、救うのが専門家でなく身内の耳打ちである所、相手が泣く場面が無い所が違う。段の並びが違うので新しい骨組み。

## 手順

1. 家族の一言を1つ決める。家族の集まりで、語り手だけができない事・違う所を言う一言にする。最後の「言われない／言われる」でこの一言を逆にする
2. 仕組みは「行き先を決める物が弱ると、別の所へ行く」の1本だけにし、着地の記事の因果で書く。試した物は記事の「試したもの」から取り、まとめて「壊れた所に足しているだけ」で外す
3. 3か月後の「やめた」は、入口の段（例: 靴・歩く距離・誘い・夕飯）を1つずつ当てる
