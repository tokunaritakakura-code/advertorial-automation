# T32 声なしで品を1点ずつ見せる型 — 分解（左側の正本）

読む人: この型で台本を書く係。
読む時: この型で新しい台本を作る前。
読まなくていい条件: すでに書いた台本を直すだけの時（その台本の中の表を見る）。

## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 声なし | 語り手がいない。音は音楽だけで、最初から最後まで止まらない。言葉は画面に映る文字だけ |
| 舞台 | 全部のカットで同じ1つの場所。参考は青い空の背景に花を敷いた夢の庭（物語の世界）。品が替わっても舞台は替えない |
| 品 | 1カットごとに見せる1点。参考は服とバッグの約20点。台本では、うちの商品が入る先（アルコットなら靴）に差し替える |
| 全身 | 品を身につけた人が、舞台の中で立つ・しゃがむ・歩く画。文字は出さない |
| 寄り | 品に刷られた・縫われた言葉や柄に寄る画。ここで文字を読ませる |
| 合言葉 | 品に刷られた言葉のうち、何度も出てくる物。参考は `VELARIS`（4回）・`Night Court`（3回）・`I love you… thorns and all`（2回）・`To the stars who listen…`（2回）。見る人が知っている世界の言葉で、品が替わっても同じ世界にいると分からせる |
| ロゴで挟む | 頭と終わりの2回だけ、同じロゴを舞台の上に出す。値段・保証・呼びかけは画面に出さない（広告文と着地に任せる） |

## 一行で

**声を使わず、見る人が好きな世界（舞台）の画にロゴを出して呼び止め、同じ舞台で品を1点ずつ「全身→寄り（品に刷った合言葉）」と20点ほど続けて、品ぞろえそのものを見せ、最後の品の上に同じロゴを出して終わる（74秒）。**

並べて落とす型（T04・T10）とは、品を比べて落とさず、全部を残して並べる所が違う。中身が順に名乗る型（T17）とは、名乗る声も順番の言葉も無く、画と品に刷った言葉だけで進む所が違う。今ある型は全部、語り手の声で話を進めるので、声なしで段を持たないこの並びは新しい番号にした。
