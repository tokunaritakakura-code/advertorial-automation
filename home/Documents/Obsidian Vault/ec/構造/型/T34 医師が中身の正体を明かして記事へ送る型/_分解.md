## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 語り手 | 作った本人の医師1人。車の中で白衣を着て、自撮りで話す。最後まで1人で、聞き手はいない |
| 中身 | 商品に入っている物のうち、1つだけ（参考はアルジルリン）。1文目で、人が呼ぶあだ名を先に言い、2文目で本当の名前を言う |

| 今の処置 | 見る人が知っている手当てのうち、見る人が知る中で1番上の物（参考はボトックス）。効くが、代わりに払う物（針・固まった顔・800ドル・3か月ごと）を並べる |
| 引き換え | 参考の `The tradeoff`。中身の手間を医師が自分から1つだけ言う（毎日塗る）。すぐに「でも数秒」と小さくする |
| まるで違う | 参考の `very different`。今の処置の代償を、中身が1つずつ裏返す段の入り口の語 |
| うそみたい | 参考の `too good to be true`。働きを言う前に、聞く人の疑いを先に口に出す語。1段目の最後に1回だけ |
| 働き | 中身が体にする事（参考は筋肉を止めずにゆるめる）。1段目では言わずに伏せ、4段目で言う |
| だから | 前の文が理由で、次の文が医師のした事、とつなぐ語。7段目→8段目のつなぎに使う |
| 全部 | 9段目で並べる、中身1つでは届かない悩みの残り（参考は4つ）と、それをまとめて書いた記事 |
| 飾り | 参考の `decoration`。ほかの会社も同じ中身の名前を書くが、量が少なく、売るための物で顔のための物ではない、と言う所 |
| 見ていられなかった | 参考の `I just couldn't sit with that`。医師が作った理由。お金を払ってだまされる女性を見てきた、という見てきた事から言う |
| さらに足した | 参考の `I didn't stop there`。中身1つでは悩みの1つにしか効かないので、50代の顔に起きている他の物にも手を打った、と言う所 |
| 記事 | 参考の `they write entire articles about us`。最後は値段も保証も言わず、「全部書いてある記事がある」と記事へ送る |

## 一行で

**作った医師が車の中で小瓶を見せ、「人は〇〇と呼ぶが、本当の名前は△△」と中身1つの正体を明かし→毎日の小さな動きが何年も重なって跡になる仕組み→今の処置（注射）は効くが、針・固まった顔・800ドル・3か月ごと→この中身はまるで違う（止めずにゆるめる・針なし）→引き換えは毎日塗る事、でも数秒→ほかの会社も名前は書くが量は飾り→お金を払う女性を見ていられず、自分の診療所の濃さで作った→それでも1つでは足りない、50過ぎの顔には他の事も起きている→さらに足した→今では記事になった、下にリンク（84秒）。値段・保証・値引きは言わない。**

専門家が業界の思い込みを斬る（T01・T20）とは、専門家が話すのは同じだが、「業界の思い込み」を外さず、聞き手もおらず、「業界がやらない理由」も無い所が違う。斬る相手は業界の考え方ではなく、同じ中身を少しだけ入れる他社の量で、話の芯は中身1つの正体と量。仕組みを解き明かす（T07・T08・T13・T23）とは、仕組みは2文だけで、壊れた連鎖を順に追わず、すぐ今の処置との比べに行く所が違う。創業者が値引きの理由を話す（T12）とは、作った本人が話すのは同じだが、値引きも在庫の話も無く、最後は記事へ送る所が違う。段の並びが違うので新しい番号にした。
