## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 生き物の工夫 | 自然の生き物が、困った事を自分の体で片づけている話（参考は、ミツバチが巣に入ったネズミをプロポリスで包んで腐らせない）。1文目は「本当に〜する」と言い切る驚く事実 |
| 困り事 | 参考の `But here's the problem`。生き物が、普通のやり方を使えない理由（ネズミが大きすぎて運び出せない）。この「できない」が、後で商品の「足せない・重ねられない」と重なる |
| 驚く手 | 参考の `something incredible`。生き物が自分で作る物（プロポリス）で困り事を片づける所。何が効いているかを1つだけ言う |
| 問い返し | 参考の `The bacteria ...?` → `cannot survive`。悪者を問いの形で出し、すぐ「生きられない」と切る2文 |
| 悪くない | 参考の `they're decent`。今ある物を否定せず、効き目の数字（3倍）まで先に認める言い方。外すのは次の段の1点だけ |
| 生きられない | 参考の `cannot survive`。悪者（菌・カビ）が、生き物の作る物の中や商品の中では増えられない、と言い切る語。4段と8段で同じ語を2回使い、生き物と商品をつなぐ |
| 同じように働いたら | 参考の `What if your bread bag worked the same way?`。生き物の話から商品の話へ渡る、ただ1つの橋。ここで初めて見る人の持ち物が出る |
| 今ある物を認める | 参考の `already exist, and they're decent`。今ある物の材料を3つ並べ、作りの良い物なら効く（参考は「最大3倍長く持つ」）、と先に正直に言う |
| どこもやらない一点 | 参考の `not a single brand ...`。今ある物のどれにも無い1点。そのせいで悩みがまだ残る（カビはまだ入る） |
| 借りた時間 | 参考の `on borrowed time`。悩みが残っている今の見る人の姿を、1文で言う |
| 入れた | 参考の `LoafGuard changed that`。商品名を言い、どこもやらない一点を入れたと言う。材料は同じ、違うのはその一点 |
| 日数の実演 | 参考の `eight days`。実物を見せ、「外は・中は・〜1つない」と3つの短い文で確かめる |
| 自然の締め | 参考の `working in beehives for millions of years`。保証の後、「自然はずっと昔からやっている」で1話目に戻して閉じる |

## 一行で

**自然の生き物の驚く工夫で呼び止め（蜂がネズミをミイラにする）→生き物の困り事（運び出せない）→だから自分で作る物で包む→悪者は生きられず、いつまでも保たれる→「もし〇〇が同じように働いたら？」で商品の話へ渡る→今ある物は悪くないと材料と効き目を認める→でもどこもやらない一点のせいで悩みが残る→商品がその一点を入れた→実物を日数で見せて3つ確かめる→普通の物ではこうはいかない→90日返金→「自然は何百万年もやってきた」で締め・リンク（98秒）。値引きは言わない。**

並べて落とす（T04・T10）とは、今ある物を落とさずに「悪くない」と認める所が違う。試した物を否定して並べる（T05）とは、否定するのは1点だけで、根っこの仕組みも語らない所が違う。仕組みを解き明かす（T07・T08・T13・T23）とは、仕組みを見る人の体ではなく別の生き物で見せ、その工夫を商品に移す所が違う。旅先で知らずに使った物の正体を探す（T30）とは、語り手の物語も、土地の人も、家族の場面も無い所が違う。段の並びが違うので新しい番号にした。

## 手順

1. 生き物の工夫を1つ選ぶ。商品の仕組みと「何を足さずに守るか」が重なる物にする。事実として本当の事だけ使う
2. ブランドの `05 VSL/02 構造で作る/T35 生き物の工夫から商品へつなぐ型/` に台本を1枚作る（[[_VSLの書類の型]]）
3. 商品が生き物を真似て作られた、とは言わない（作った人の話に無ければ）。橋は「もし〇〇が同じように働いたら？」の問いにする
