## 何に当てている記事か（逆算の答え）

**この4つが型の中身。並びだけ真似ても、ここがずれたら別物になる。**

| 部品 | メラオが当てている物 |
|---|---|
| **痛み** | 足の裏の灼熱・ビリビリ。**夜に強くなる**。検査では異常なし |
| **ターゲット** | 50〜70代。病院を回り切って「加齢ですね」で終わった人。薬・注射・サプリ・器具で**14個・20万円**使い切っている。**買うのは本人だけではない。「大丈夫？」としか言えない家族が4倍いる** |
| **今の解決策** | 飲む（薬・サプリ）／注す（ブロック注射）／切る（手術）。**全部、体の中心から入れようとしている** |
| **売る解決策** | 皮膚から入れる（経皮）。**「第3の入り口」と名前を付ける** |

### 押している感情（順番も型のうち）

| # | 感情 | どこで押すか | 実文 |
|---|---|---|---|
| 1 | **見捨てられた怒り** | 節1 | 「異常なし」「加齢ですね」──そして、薬の行き止まり |
| 2 | **自分のせいではないという赦し** | 節3 | だらしないせいでも、運動不足のせいでもありません |
| 3 | **まだ間に合うという希望** | 節2 | 感じているうちは、神経はまだ生きています |
| 4 | **時間切れの恐怖** | 節13 | 今夜より来年の夜の方が、条件は悪くなっていきます |
| 5 | **無力な家族の罪悪感** | 節8・締め | 「大丈夫？」と聞くことしかできなかった家族に、初めて手でしてあげられる |

**3と4は必ず対で置く。**希望だけだと今日買わない。恐怖だけだと閉じる。

### エンジン（この型が効いている理屈）

```
今まで試した物を全部並べる（数と金額つき）
  ↓
効かない理由を1つずつ言うのではなく、全部に共通する1つを見つける  ← ここが型の芯
  ↓
その共通点＝「入り口」。その入り口が詰まっていると示す
  ↓
別の入り口があると言い、名前を付ける（第3の入り口）
  ↓
その入り口を通れる物の条件を2〜3個に絞る
  ↓
条件を満たす物として商品を出す
```

**「商品がいい」ではなく「入り口が違う」で売っている。**だから、今まで全部だめだった人が、自分が悪かったのではないと思える。

## 言葉の定義

| 言葉 | この1枚での意味 |
|---|---|
| 痛み | 記事が名指しする症状と、それが強く出る時刻。時刻が入っていない物は痛みとして扱わない |
| 入り口 | 手当てを体に届ける経路。飲む（胃腸）・注す（血液）・塗る（皮膚）、時間で言えば「仕事の後」「仕事の最中」 |
| 第3の入り口 | メラオが自分の経路に付けた名前。うちの記事では別の名前を付け直す（例「8時間目の支え」） |
| 蛍光 | 本文に引く黄色のマーカー（`.highlight`）。節を1文に畳んだ時に残る文だけに引く |
| 太字 | `<strong>`。数字・客の逐語の核心句・章の結論1文・成分ラベル・否定リストのラベル語の5種だけに使う |
| 太字ゼロ | その節に `<strong>` を1つも置かないこと。落差・手順・FAQの3節で守る |
| 引用 | 客が書いた原文の引用ブロック（`.blockquote`）。言い換えない。前に必ず前置きを置く |
| 画像 | 記事に貼るフル幅の図・写真・動画。見出しの直後か章の途中に置く |
| CTA | 注文ページへ送るボタン。本文中に置く物（5つ）と、画面下に貼りつく浮遊ボタン（1つ）がある |
| 加齢ですね | 病院が症状を終わらせる時の決まり文句。記事はこれを「見捨てられた」の合図として引用で置く |
| まだ間に合う | 症状がまだ軽い段階にいるという言い方。恐怖（放っておくと進む）と必ず対で置く |

## この型をうちに当てる時の10個の問い（埋まるまで書き始めない）

1. 痛みは何か。**いつ強くなるか**（メラオは夜。時刻が入っていないと名指しにならない）
2. その人は今まで何を試したか。**数と金額は？**
3. 病院・専門家は何と言って終わらせたか
4. 試した物**全部に共通する1つ**は何か ← **ここが型の芯。出なければ、この型は使えない**
5. その共通点を「入り口」と呼ぶと、詰まっているのはどこか
6. 別の入り口は何か。**名前は？**（第3の入り口／8時間目の支え）
7. その入り口を通れる物の条件は2〜3個。何か
8. 客が**自分の記憶で確かめられる物差し**は何か（メラオは無い。うちは「夕方に押して戻るか」）
9. 恐怖の核は何か。**放っておくと何が進むか**（時刻・範囲・年数のどれかで進ませる）
10. 買うのが本人でない場合、**その人は誰で、何ができないでいるか**
