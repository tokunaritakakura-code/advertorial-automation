## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 敵 | 悩みの原因そのもの（参考では一酸化炭素）。一人称で語り、見る人の家族を「毎年何千人も殺す」と自慢する。目に見えず、音もにおいもしない |
| 眠っている間 | 敵が働く時。見る人の家族が気づかないまま被害に遭う、を「眠っている間に殺す」で言う段 |
| 隠れ場所 | 敵が「わたしは〇〇の中にいる」と1つずつ名乗る、暮らしの中の場所（参考では熱交換器・コンロのパッキン・排気の煙突・冷蔵庫・隣の発電機・トラックの排気の6つ） |
| 名乗り | 隠れ場所を並べた後に、敵が「わたしは〇〇」と正体の名前を言う1行 |
| 今の守り | 見る人の家族がもう持っている物のうち1つ目（参考では天井の煙探知機）。敵は「あれはわたしを見つけられない。わたしは気体だ。毎回その横を素通りする」と笑う |
| 安物の守り | 2つ目に持っている物（参考ではホームセンターの一酸化炭素の警報器）。敵は「数字がここに届くまで黙っているように作られている」と、作りの穴を数字で言う |
| 体の数字 | 敵が体に何を起こすかを、数字で2段（30で体が壊れ始める・50でもう反応しない）言う所。安物の守りが黙る数字（70）より小さい |
| 言い返す | 敵が「誰もわたしを止められない」と言った直後に、商品が一人称で「いいや。わたしは0から見ている」と割って入る段。商品はここで初めて声を出す |
| 専門家 | 商品の後に出て「わたしはN年この仕事をしている。今の守りが動いていて安物の守りが黙ったままの家から、人を運び出してきた」と証言し、「これはわたし自身が使っている物」と言う人（参考では消防士27年） |
| 見えない | 敵の性質。目で見えず、においも味もしない事。敵が気づかれない理由として、段3と段6で2回言う |
| 見つけられない | 今の守りが敵に対してできない事。敵が気体なので煙探知機の横を素通りする、を敵の側から言う言葉 |
| わたしは〇〇 | 敵が隠れ場所と正体を一人称で名乗る言い方（「わたしは熱交換器の中にいる」「わたしは一酸化炭素」）。商品も同じ形で「わたしは0から見ている」と言い返す |
| いいや | 商品が言い返す最初の1語（参考では Doch）。敵の「誰も止められない」を、この1語で裏返す |
| 本当の数字 | 専門家が締めで言う商品の違い（参考では「光の代わりに本当の数字を。光は嘘をつく」）。安物の守りの「光」と対にする |

## 一行で

**敵（原因そのもの）が一人称で「毎年何千人も殺している、ほとんどは眠っている間に」と自慢して入り、隠れ場所を6つ並べ、名乗り、今の守り（煙探知機）は自分を見つけられないと笑い、安物の守り（安い警報器）は数字が届くまで黙ると作りの穴を数字で言い、体の数字と逃げ場の無さを重ねて「誰も止められない」と言った所で、商品が一人称で「いいや、0から見ている」と言い返し、専門家が「N年、安物の守りが黙った家から人を運び出した。これは自分が使っている物」と証言してリンクへ送る（156秒）。**

T22（体の場所が持ち主を責める型）は悩みの場所が持ち主を責めるが、こちらは敵（原因）が被害を自慢する。T31（商品が自分の口で名乗る型）は商品が最初から最後まで語るが、こちらは敵が3分の2を語り、商品は言い返す1段だけ。T09（本当の危険は別の所）は語り手が外から説くが、こちらは敵自身が今の守りの穴を笑う。段の並び（敵の自慢→隠れ場所→名乗り→今の守り→安物の守りの数字→体の数字→誰も止められない→商品が言い返す→専門家→リンク）が既存のどの骨組みとも違うので新しい番号にした。
