## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 私 | 語り手。悩みを抱えた本人（参考は年を取った犬）。自分では買わない側で、最後まで一人称で話す |
| ママ | 私を大事にしている身近な人（参考は飼い主）。「年のせい」と片づけ、途中で泣き、最後に商品を見つけて買う側 |
| いつもの楽しみ | 2人で毎回している事（参考はいつもの散歩）。ここで私が止まるのが底。最後に同じ場面が逆になって戻る |
| 専門家 | 原因と要る物を言う人（参考は獣医）。ブランド名は言わない。名前を見つけるのはママ |
| 仲間 | 私と同じ悩みの人たち。締めで「同じ悩みの仲間へ」と私が呼びかける相手 |
| 伝えたかった | フックの言葉。私は困っているのに、ママに届いていない事。締めの「あなたの人に話して」で回収する |
| 玄関 | 前は私が迎えに出ていた場所。今は出られない。3週間後にまた迎えに出る。前と今と後を同じ場所で比べる |
| 要る物 | 専門家が挙げる、足りない支えを補う物（参考は成分4組）。台本では着地の記事が言う条件に差し替える |

## 一行で

**悩む本人が一人称で「前の私じゃないと伝えたかった」と始め、前と今の場面を比べ、身近な人に「年のせい」と片づけられ、いつもの楽しみの途中で動けなくなって相手が泣き、専門家が原因と要る物を挙げ、相手がその夜に商品を見つけ、3週間後に同じ場面が逆になって相手がうれし泣きし、仲間も大勢いると広げてから、同じ悩みの仲間に「あなたの人に話して」と呼びかけ、在庫で締める（139秒）。**

買った本人が語る型（T03）とは、語り手が買う人ではなく「買ってもらう側」で、身近な人の思い込み（年のせい）と泣く場面を2回置く所が違う。身近な人が買って語る型（T02・T21）とは語り手が逆。体の場所が責める型（T22）とは、責めずに、相手を思う側から話す所が違う。段の並びが違うので新しい番号にした。
