## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 数えるサイン | フックで見る人に数えさせる、毎日の小さな回数（参考は「2回より多く拭く」「ロールの半分」）。本人が「癖」だと思っている物 |
| 本来の作り | 崩れる前の体（または道具）。参考では、上がったコルチゾールが1回ずつ下がっていたの仕組み。参考はコルチゾールが少しずつ出て、上がって下がる |
| 壊した物 | 本来の作りを崩した、今の暮らしの側の原因。参考は止まらないストレス |
| 〜な体 | 連鎖の最後に付ける名前。参考は「コルチゾールに閉じ込められた体」 |
| 一部しか触らない | ほかの解決策が効かない理由。1つずつしか触らず、原因の合図に届かない |
| トイレの癖 | 本人が「自分のやり方」だと思っている回数 |
| 癖じゃない | フックの言い替え。トイレの癖を外し、体の赤信号だと言い直す言葉 |
| 効かない | 「〜は効かない」とみんなが言う、の意味。5段目で「一部しか触らないから」と理由を付けて受ける |
| 中身4つ | 商品が1つにまとめた4つ。1つずつ「何をするか」を1文で言う |

## 一行で

**毎日数えられる小さな回数で呼び、「癖じゃない、体の赤信号」と言い替え、体の本来の作り→今の暮らしが壊した→その先の連鎖を1文ずつ図で見せて名前を付け、「ほかは一部しか触らない」で外してから、要る4つを1つにまとめた商品の中身を1つずつ言い、3日目・7日目の変化、足さなくていい物、安い版が効かない理由、50%オフで止める（137秒）。**

T18（日を追って中で効く型）は最初に日を並べてから中の話をする。T17（中身が順に名乗る型）は中身が一人称で名乗る。T23は、数えるサインの言い替え→本来の作り→壊した物→連鎖、という「仕組みの説明」が前半の半分を占め、商品は1:15まで出ない。段の並びが違うので新しい番号にした。
