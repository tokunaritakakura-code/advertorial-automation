# 必ず入れる物（参考に無くても、どの型の記事にも足す物）

読む人: 記事・アンケートLP・クイズ・リスティクルを作る Claude と、出来た物を審査する Claude。
読む時: 移植表を書き終えた後（参考を写した後）に、足す所を決める時。審査の時。
読まなくていい条件: なし。

記事の中身の出どころは2つ。1つ目は参考の写し（参考との差を0にする）。2つ目がこの一覧で、うちで効くと分かっている物を、参考に無くても足す。ここに載せてよいのは、本人が決めた物か、うちの配信で効いた数字が取れた物だけ（2026-10-10 本人）。

## 言葉

| 言葉 | 意味 |
|---|---|
| 場所 | 足す物を置く段。参考の中で、足す物と同じ仕事をしている段（例: 最初の画面・値段の段） |
| 最後まで読 | 「最後まで読んでほしい」の文を機械が数える時の字。下の行と同じ物 |
| 最後まで読んでほしい | 最悪の結末の後に、書き手の気持ちとして「最後まで読んでほしい」を伝える1文。ページに1回だけ（機械は「最後まで読」の字で数える） |
| 見た目 | 足す物の部品の形・字の大きさ・色・枠。値段の段は ここちドライの欄（`欄のCSS.html` の価格の箱・セットのカード・ボタン）の形に合わせ、色だけ記事のテーマの色にする |
| 審査 | 作った AI とは別の、新しい文脈の AI（Opus）に、出来た物と決まりを渡して PASS か FAIL を判定させること |

## 足し方の決まり（全部の物で同じ）

1. **場所**: 参考の中で、同じ仕事をしている段に足す。参考の段の並びは変えない（足すだけ）
2. **見た目**: 参考の中にある、足す物と同じ形の部品（箱・帯・✅の並び・値段の箱）をそのまま使う。字の大きさ・色・行の長さは、すぐ上の段と同じにする
3. **文**: 前の文と後の文に1文でつながるようにし、語尾と言い方を周りに合わせる。最悪の結末を、怖さを扱わないページ（好み・性格を聞く診断）に足す時は、枠のすぐ後に「その結末を避けるために、このページが何をするか」を1行で言う（例: 「だから、あなたに合う吸水ショーツを7問で見つけます」）。つなぎが無いと、枠の後で何のページか分からなくなる（2026-10-10 7問の診断で、読み手の目が8回中6回挙げた）
4. **印**: 足した段の枠に `data-tasu="<下の表の番号>"` を付ける（機械の検査が数える・段ごとの読了率を比べる）
5. **審査**: 別の AI に、参考も足した場所も見せず、出来た物の画面だけを渡して「浮いて見える・流れが切れる所」を強・中・弱つきで挙げさせる。足した段が強か中で挙がったら、見た目か文が浮いているので2〜3に戻って直す（足した場所を教えたり参考と並べたりすると、浮いていなくても当たるので確かめにならない）
