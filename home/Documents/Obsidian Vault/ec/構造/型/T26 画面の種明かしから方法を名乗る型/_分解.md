# T26 画面の種明かしから方法を名乗る型 — 分解（左側の正本）

読む人: この型で台本を書く係。
読む時: この型で新しい台本を作る前。
読まなくていい条件: すでに書いた台本を直すだけの時（その台本の中の表を見る）。

## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 種明かし | 0秒の画に映っている物が、見たままの物ではないと明かす1文（参考は「ここに見えている女の子は、実在しない」）。呼び止めるための物 |
| 作った本人 | 種明かしの後に顔を出して話す人（参考は講座の主。AIの女の子から実写の本人へ切り替わる）。一人称で「こう作って、こう使っている」と言う |
| やり方の名前 | 本人が自分のやり方に付けた名前（参考は「ドロップブランディング」）。2つの物の合わせ技だと言う |
| 合わせ技 | やり方の名前の中身。参考は「ブランドを付けたドロップシッピング」と「AI」の2つ |
| 行き先 | 見る人に開かせる所（参考はプロフィール）。途中で1回、最後にもう1回言う |
| 合言葉 | 最後の「もっと知りたいならDMで『DB』と書いて」。うちに無い物なので、買う前に迷う事の問いと答え（いちばん上のセット）に当てる |
| modello | 参考の「形」。本人が人に渡している稼ぎ方の一式で、やり方と同じ物を指す |
| DB | 参考の合言葉の2文字（drop branding の頭文字）。DMに書くと本人が説明する |
| AI | 参考の「intelligenza artificiale」。0〜3秒の女性を作った道具で、合わせ技の2つ目 |
| やり方 | 参考の「metodo」と、その言い換えの「modello」（形）。本人が売っている稼ぎ方の一式。うちでは商品の作り（受け口と吸水の層）に当たる |
| 実在しない | 種明かしの中身。画の女性はAIで作った人で、本当はいない |
| 数字 | 本人が言う売上の数（1日2000ユーロ・30日で9万ドル）。うちでは商品ページにある量（コップ1杯分）に当たる |
| 結果 | ゼロから始めた人が同じやり方で出した売上（60日で3万ドル・12か月で50万ドル）。うちでは商品ページが言う、戻れる毎日に当たる |

## 一行で

**0秒の画を「見たままの物じゃない」と種明かしして呼び止め、作った本人が「こう作って、こう使い、ここまで出た」と数字で言い、早めに行き先を言い、やり方に名前を付けて2つの合わせ技だと明かし、合わせたから何が違うか（質・早さ・利幅・初日から勝つ・大手と争わない・長く続く）を並べ、ゼロから始めた人が同じやり方で出した結果を言い、もう一度行き先と合言葉で締める（81秒）。**

創業者が値引きの理由を話す型（T12）とは、作った本人が話す所は同じでも、値引きや在庫の理由が無く、種明かしとやり方の名前（合わせ技）が話の芯になっている所が違う。仕組みを解き明かす型（T07・T08・T13・T23）とは、体の中の悪循環を見せず、作りの2つを合わせた事だけで説明する所が違う。買った本人が語る型（T03）とは、前の悩みから入らず、画の種明かしから入る所が違う。段の並びが違うので新しい番号にした。
