# advertorial（広告と商品ページの間に挟む記事型の1枚）

## いつ読む
広告のクリック先を作る時。挟むかを決める所から、ブロックを並べ、公開直前の法務検査まで。
枠の中身を実話にする部品（語り手・低点・変化・律動）は [[advertorial-story]] を続けて読む。
**2本セットで1本の広告になる。**

## 共通の型
アドバトリアルは商品を売る場所ではなく、**商品ページが売れる状態を先に作る場所**である。
独立した4本の教材（構成表・記事枠のネイティブ論・長文ネイティブ講座・直販講座）が、
媒体も国も違うのに同じ順路を出している。読者は3つの負債を持って着地する。
クリック元との話のズレ、他人事のままの問題、全部を疑っている状態。
順路はこれを1つずつ返す作業になる。
**クリック元の言葉を書き出しでそのまま受け取り、問題を1つの場面として描き直し、
原因の新しい見方（メカニズム）を因果で1段ずつ渡し、
読者が黙って持っている反論を口に出される前に答え、
大きな主張の前に読者が自分で確かめられる小さな真実を積み、最後に買うものを1つだけ出す。**
固定なのはこの順路と「負の感情 → 正の感情 → 行動」の大枠だけで、
ブロックの数・語数・各部の長さは固定しない（2026-08-15-landra-advertorial#c01）。
長さを動かす基準は**前段の広告が何を消化したか**で、静止画広告の後は長く、動画広告の後は短くする。

## 手順

### サブゴール1: 挟むかどうかと、材料を確定する
1. 広告→商品ページ直行のファネルなら、CPAとAOVを見る。CPAが目標を超え、かつ複数買いが出ていないなら1枚挟む（2026-08-15-rmbc2-advertorials#c01）
2. 挟むと数字は2方向で動く。CPAが下がり、長文を読んだ読者が複数買いを取るのでAOVが上がる（2026-08-15-rmbc2-advertorials#c02）
3. 挟むと決めたら商品ページは基本形のまま固定する。以後テストするのは広告とアドバトリアルの2つだけにする（2026-08-15-rmbc2-advertorials#c03）
4. 「アドバトリアル」の見た目にこだわらない。割引案内ページ・比較ページでも、下ごしらえを肩代わりするなら同じ役割（2026-08-15-rmbc2-advertorials#c20）
5. スワイプは英語圏の地方ニュース記事下の推薦枠から採る。都市名とシークレットウィンドウで配信を変え、リンクが死ぬ前に全文コピーとスクリーンショットを保存する（2026-08-15-rmbc2-advertorials#c15）
6. 集めた例はわざと別カテゴリを混ぜる。同ニッチだけを集めない（2026-08-15-rmbc2-advertorials#c13）
7. 前段の広告のキャプションを手元に置き、物語をその広告と同じにする（2026-08-15-rmbc2-advertorials#c17）
8. 前段が静止画なら長い物語型、1〜2分の動画なら短い型を選ぶ（2026-08-15-rmbc2-advertorials#c07）。語数は150〜2,500語の幅で先に決めてから書く（2026-08-15-rmbc2-advertorials#c06）

### サブゴール2: クリックの続きとして受け取る
9. 見出しに「解決する問題か満たす欲求」と「誰に向けた話か」の両方を入れる。煽り文句だけにしない（2026-08-14-advertorial-structure#c01）
10. 書き出しはクリック元の見出しの言葉をそのまま使う。話を仕切り直さない。「多くの人が知らないことですが」で始めない（2026-08-15-landra-advertorial#c02）
11. 導入は1文で掴み、解決する問題を短く出すだけにする。詳細は次のブロックに送る（2026-08-14-advertorial-structure#c02）
12. 冒頭の読後感は「好奇心 → 個人的・感情的 → 教育的」の順にする。教育から入らない（2026-08-15-rmbc2-advertorials#c04）
13. **PR表記が見えている前提で書く。隠れているつもりで書かない**（2026-08-15-landra-advertorial#c03）。ただし「表記は出す」と「読み口を広告に見せない」は両立する。**個人の打ち明け話の形はそのまま使ってよい**。禁じ手は表記を消すことと、広告枠の外でオーガニック投稿を装うこと（詳細は [[advertorial-story]]）

### サブゴール3: 他人事を自分事にする
14. 問題ブロックを厚く書く。統計か実話で具体化する（2026-08-14-advertorial-structure#c03）
15. 放置した場合の帰結を書く。原型は根本原因を名指しして身体的損傷まで断定する型だが（2026-08-15-rmbc2-advertorials#c08）、**日本では薬機法で不可。症状名・疾患名・損傷の断定を使わず、生活上の困りごとが積み上がる形（眠れない日が続く／出かけるのが億劫になる）に置き換える**

### サブゴール4: 新しい見方を渡して、疑いを外す
16. 商品は「解決策」として出す。売り込みの言葉で始めない（2026-08-14-advertorial-structure#c04）
17. 社会的証明は本文に散らして入れる（2026-08-14-advertorial-structure#c06）。囲みや末尾にまとめず、**主張と同じ文の中**に置く（2026-08-15-landra-advertorial#c06）
18. ベネフィットは機能ではなく結果で書く。**商品ページでは箇条書き、物語型の本文では散文**にする（2026-08-14-advertorial-structure#c05。お手本の医師広告は箇条書きゼロで成立している）
19. 反論を読者が言い出す前に潰す（2026-08-14-advertorial-structure#c07）。冷たい流入なら、メカニズムと価格提示の間に反論を1つと証拠を1つ足す（2026-08-15-landra-advertorial#c07）
20. 数字は必ず同じ文に出典を書く。出典を書けない数字は消す（2026-08-15-landra-advertorial#c04）
21. 効能は断定しない。体の働きを支える言い方に留める（2026-08-15-landra-advertorial#c05）

### サブゴール5: 動かす
22. 買うもの（オファー）は1つに絞り、CTAは1種類にして本文中で繰り返す（2026-08-15-landra-advertorial#c08、2026-08-14-advertorial-structure#c08）
23. ただし**買う理由（動機）は複数出してよい**。複数買いはバンドル表示ではなく、本文の主人公の行動として書く（2026-08-15-rmbc2-advertorials#c10）
24. 価格は代替手段の金額を先に置いて錨にしてから出し、第三者・レビュアーの立場から妥当化する（2026-08-15-rmbc2-advertorials#c09）
25. ボタンの文言に「押したら何が起きるか」を書く（2026-08-15-landra-advertorial#c08）

### サブゴール5.5: LLMに書かせる時の順番（2026-08-17 追加）

**丸投げしない。** 出典 2026-08-17-mark-advertorial-lp-ai。

1. 4つの書類（リサーチ / アバター / オファーブリーフ / 必要な信念）を先に揃える。
   うちでは `/deep-customer` の3枚と `/hard-docs` の4枚がそれに当たる。**無いまま書かせない**
2. **他人の記事を貼って「書き直して」から始めない**（#c02）。表面の言い回しだけが移り、
   その文が効いていた理由が移らない。スワイプは4書類の後に、型として1本だけ選ぶ
3. **前半だけ書かせる**（#c03）。角度が合っているか確かめてから後半に進む。一度に全部書かせない
4. 全文が揃ったら、**設計どおりかをAIに検査させる**。観点は6つ
   （必要な信念に沿っているか / 独自メカニズムが明示されているか / 反論を先回りしているか /
   外部の敵が置かれているか / リスクの引き受けがあるか / 認知段階と市場の擦れ具合に合っているか）
5. **その後で人が読む**（#c07）。基準は**滑り台**（#c08）。引っかかる所が転換率を落としている所

### サブゴール5.8: CTAの直前で現状に引き戻す（2026-08-17 追加・仮説）

理想の状態を見せたまま行動を求めない。**CTA の直前で、今の現実に一度引き戻す**
（2026-08-17-mark-neuroscience-of-buying#c07, #c08）。落差が動機になる。

- 引き戻し方は**現状の描写**にとどめる（「今夜もまた、同じ姿勢で画面を見る」）。
  **症状の悪化を予告しない**（薬機法）
- 原典はCTA直前にチェックリスト型の問い（「〜が出ていませんか」→「はい」）を置いている。
  日本では症状名を医学用語にせず、生活の言葉で書く
- **本人も「やっている人をほぼ見ない」と言う設計案**なので、既存の型と並走させて測る

### サブゴール6: 出す前に検査する
26. LLMで書く順序を固定する。(1)勝ち例を渡して構造の詳細なアウトラインを作らせる（2026-08-15-rmbc2-advertorials#c11）(2)フック案を10個出させる (3)選んだフックで指定の長さのアウトライン (4)アウトラインで蛇行がないか確認してから本文（2026-08-15-rmbc2-advertorials#c16）
27. 生成機を1つ立てる。ナレッジベースには長さと系統を混ぜた例を入れ、「まず各例の構造を分析し、統合してから新しく書け」を指示文にする（2026-08-15-rmbc2-advertorials#c12）
28. 短縮の指示は「約20%短く」のように幅を持たせる。保証日数・成分量など事実の指示は正確に出す（2026-08-15-rmbc2-advertorials#c18）
29. 出力を第三者として読み直し、論理が飛んでいる箇所に橋を足す。生成物の数字は必ず原典に当たって照合する（2026-08-15-rmbc2-advertorials#c19）
30. 推敲を1回入れる。誤字と、目的からのズレを見る（2026-08-14-advertorial-structure#c09）
31. 法務を最後に3点通す。**薬機法**（効能効果の断定・症状名・医薬関係者の推薦を使っていないか）、**ステマ規制**（PR表記が消えていないか。広告枠の外に置いていないか）、**景表法**（出典のない数字・根拠のない最上級や比較優良・事実でない在庫や期限・事実でない体験談がないか）
32. ニッチが違うという理由で他ジャンルの勝ち構文を切り捨てない。移植するのは題材ではなく構造と構文（2026-08-15-rmbc2-advertorials#c14）

## 判断基準
- 語数の幅: 150〜2,500語
- 前段が1〜2分の動画なら短い型、静止画なら長い型
- 冷たい流入では反論+1・証拠+1（合計2ブロック追加）
- フック案は1回のプロンプトで10個出させる
- 短縮指示の幅は約20〜25%
- 固定するページ数は1（商品ページ）。可変は広告とアドバトリアルの2つ
- 出典の書けない数字は0個
- 挟む前に揃える前提は5つ（コピー・客層・認知段階・心理と痛み・商品とメカニズムの筋）
- 社会的証明の本数: **基準なし。教材4本すべてが数を言っていない**
- **見出しが記事全体の9割を引く**（2026-08-17-mark-advertorial-lp-ai#c04）。直す順番は見出しが先
- 見出しには**開いた輪**（続きが気になる形）を必ず作る（2026-08-17-mark-advertorial-lp-ai#c05）。
  販売ページの見出しより好奇心の比重を大きくする
- **反論はFAQで処理しない。記事の中で、商品ページに着く前に潰す**（2026-08-17-mark-advertorial-lp-ai#c06）
- **安さで探されている市場には入らない**（2026-08-17-mark-advertorial-lp-ai#c09）。価格で来た客は価格で去る

## お手本
**現物1: 医師名義の長文ネイティブ広告**（2026-08-15-konvert-native-casestudy-doctor#c01）。
15ブロック。脅威フック → 名乗りと動機 → 発端＝他人の症例 → 反復「毎週見ている」 →
読者の内心の再現 → メカニズム → 体制への怒り → 書き手の低点 → 発見と懐疑 → 自分で試した経過 →
第三者での再現 → 偽物との差別化 → オファー・希少・保証 → 禁を破る告白 → 恐れに戻ってCTA。
箇条書きゼロ、全部散文。各ブロックの書き方は [[advertorial-story]]。
**成果の裏付けは一切無い**（CPA・配信期間の記載なし）。
**日本ではこのまま使えない。**医薬品・医薬部外品・化粧品・医療機器の広告に医師等の推薦は
適正広告基準で不可。雑貨・食品でも肩書きを効能の裏付けに使わない。借りるのは順序だけ。

**現物2: 家電の長尺アドバトリアル**（2026-08-15-rmbc2-advertorials#c05）。
フック → 個人の物語と危機 → 専門家の確認 → 統計で一般化 → メカニズム → 失敗した解決策 →
選択の袋小路 → 第三者の登場 → 懐疑からの試用 → 変化 → 商品名の開示 → レビュアーの信用 →
価格の妥当化 → 切迫と希少。
**別ニッチ・別講師の現物2つが同じ順路。**これが「共通の型」の根拠。

## よくある失敗
- 書き出しで話を仕切り直す → クリックで生まれた興味が切れて直帰する
- 教育から入る → 好奇心と感情を飛ばした分だけ読み進められない
- レビューを末尾にまとめる → 主張だけが独り歩きし、疑いが残ったまま値段に着く
- 出典なしの数字を置く → それ自体が根拠のない主張。日本では景表法に直結
- PR表記を消す／広告枠の外に同じものを置く → **ステマ規制違反**。読み口を広告に見せない書き方自体は問題ない
- 米国教材の効能表現をそのまま訳す → 薬機法違反。原型が断定でも日本では言い換える
- 商品ページを毎回いじる → 試行回数が増えず、どこが効いたか分からなくなる
- 生成物をそのまま出す → 必ず1つ以上の未接続の飛躍と、裏の取れない数字が残る

## まだ埋まっていない穴
- 社会的証明の必要本数。教材4本すべてが数を言っていない（3回連続で埋まらなかった）
- 各ブロックの長さの配分。「配分を固定するな」以上の答えが無い
- 比較リスティクル型（「上位5製品を比較。1位は意外」）の中身。教材が扱わずに終わっている（2026-08-15-rmbc2-advertorials#c21）
- CPA・AOVの実数。改善するとしか言っておらず、前後の数字が1つも出ていない
- お手本2本とも成果の裏付けが無い（配信継続期間だけ）
- 日本語の見出しの型と、日本の記事枠でスワイプを集める先
- 自分の広告での実証。この playbook は全行が教材のみ
