**このページは「知識」ではなく「同じミスを2度しないための関門」。**
各項目に、**それが生まれた失敗**を残してある。理由が分かっていないと守れないため。

# 1. フック（2軸そろえる。片方だけは不合格）

```
1行目：［市場の実文＝感情］          ← 「これは自分だ」
2行目：［伏せた物］＋［値札］        ← 読み続ける理由
3行目：短い一言で輪を開いたまま置く
```

**1行目に「痛み」と「数字」を両方入れる。**片方だけは不合格。

- **痛み**＝読む人に今起きていること。語り手の身の上・場面の設定・数えた結果から始めない
- **数字**＝細かいほど本当に見える。**11枚・288回・4軒**。丸めない、ぼかさない。作らない

| | 1行目 | 判定 |
|---|---|---|
| ✘ | クローゼットのタートルネックを数えたら、11枚ありました | **状況。**数字はあるが、誰の痛みでもない |
| △ | 首が短く見えるのが嫌で、タートルネックばかり買っていました | **痛みだけ。**何本なのか分からず、1秒で話が入らない |
| ○ | 首が短く見えるのが嫌で、**6年**でタートルネックを**11枚**買いました | **痛み＋数字。**買った理由＝恥に、細かい実数が付いている |

**なぜ数字が要るか**：①端数のままの実数は**本当にあった話に見える**（→ 3-5）
②流し見の1秒で「何本・何年・何回の話か」が分かるので、**中身を読む前に話が入る**

**失敗例**：くびらく10本のうち**9本が、1行目＝状況／2行目＝痛み／数字はさらに下**の順で書かれていた。
「首が短いのを隠すために買った」という**痛みが2行目に埋まっていた**（→ `ローンチ広告/フック書き直し-v3.md`）。

## 0. WTF ── これが無いフックは全部やり直し

**予想どおりのことを書いた時点で、フックは死んでいる。**
「これは自分だ」だけでは足りない。**「え、なんで？」が同時に起きないと、読み進める理由が生まれない。**

**作り方は1つ。噛み合わない2つを、1文に入れる。**
実物：「同僚にOzempic打った？と言われた。違う、首なんだよ」（142日）／
「顎が弱いんじゃない。首が詰まっている」（149日）／
「カイロにも行かず、体操も1回もせずに首のコブを直した」（149日）。

**失敗例**：長文5本とも、1行目が「2軒で治らないと言われました」型だった。**全部が予想どおりで、衝突がゼロ。**

**フックの守るリストは `playbooks/hook-checklist.md` に独立させた。1本書くたびに通す。**

## PIGは見出しに置く。本文の1行目は選別に使う

**実測**：120日稼働の広告は、見出し「7 signs your neck hump is **worse than you think**」で殴り、
本文の1行目は「If you have a neck hump…」という平たい選別条件。**役割が分かれている。**

| | 中身 | 縛り |
|---|---|---|
| **見出し** | **PIGの一撃** | **断定。質問形にしない。**「〜ませんか」は確認であって殴っていない。20〜25字。低い感情（恥・怒り・悲嘆・恐れ）から入る。**説明を足した瞬間に力が消える**〔Mark PIG c02・c03〕 |
| **本文1行目** | **選別** | 「〜な人へ」「〜したことがありますか」。ここは質問でいい |

**失敗例**：見出し15本を測ったら**15本とも質問形**だった。確認しているだけで殴っていない。

## 角度の名指し（見出しと1行目の両方に必須）

**「治りません、と2軒で言われました」は、何が治らないのか書いていない。**
肩こりとも腰とも読める。**ターゲットにしている本人が、自分の広告だと気づけない。**

- Solution Aware なら**診断名がいちばん速い自己識別のスイッチ**。そのまま置く
- 3案回すときは **1案目＝診断名／2案目・3案目＝見え方と場面**で、拾える層を分けて測る

**失敗例**：見出し15本と本文1行目5本、**計20本のうち角度が入っていたのは0本**だった。

**検査**：1行目だけを読んで、①客が自分のことだと思うか ②数字が1つ以上見えるか ③何の話か分かるか。
語り手の職業・年数・持ち物しか書いていなかったら、痛みを1行目に上げて、状況を2行目に下げる。
**数字が1行目に無いなら、本文から実数を1つ上げる。**無理に作らない（→ 3-3）。

| 軸 | 中身 | 検査 |
|---|---|---|
| **感情** | 市場が実際に書いた文をそのまま | 言い換えていないか |
| **伏せた物** | **具体的に1個**（質問／選択肢／原因／習慣）。**数えられる物** | 「秘密」「真実」「あること」は不合格 |
| **値札** | 知らなかったせいで失った量（金額／年数／回数） | 実測から取っているか |

**根拠**：勝ち広告5本のうち**4本に伏せた物、3本に値札**があった。
どちらも無い1本は稼働11日。値札のある2本は**85日と110日**。
**この2軸は教材（Konvert / Justin / Mark）のどこにも書いていない。うちの実測。**

**失敗例**：9本作って、**9本とも値札ゼロ**だった。止まる理由はあるが、読み進める理由が無い状態。

# 4. 言葉（小学5年生が初見で読める）

| # | ルール | 失敗例 |
|---|---|---|
| 4-1 | **一文の平均17字前後。**40字超は6文まで | 「価値は感じるけど分かりにくい」と言われた |
| 4-2 | **漢語を和語に** | 設計されていない→決めていない／形式→やり方／収縮→ちぢむ |
| 4-3 | **抽象的な言い回しを禁止** | 「300年続いたやり方のほうでした」「終わりが来ないやり方の中にいた」→ **何のこと？になる** |
| 4-4 | **数字は一度に1つ** | 5kg／2.5cm／4.5kg／10kg を連続で出して渋滞した |
| 4-5 | 二人称「あなた」は**8〜11回**。「私」との比は**1対1.5〜2** | 8,918字に「あなた」が**2回**しか無い版があった（Ceveraは1対1） |
| 4-6 | **短く保つ。足したら、どこかを削る** | 直すたびに長くなった |
| 4-7 | **主語と目的語を落とさない。**英語の感覚で書かない | 「9年通って、去年やめた人です」＝**何に通って、何をやめたのか書いていない。**「整体と鍼に9年通って、去年、通うのをやめた人」に直した |
| 4-8 | **指示語の受け先を毎回そろえる** | 「やめたら、戻った」「朝には元に戻っている」「押してもらっても戻る」＝**何が戻るのか全部抜けていた。**「首が」「同じ一点が」「張りが」を入れた |

**検査**：1文ずつ「誰が」「何を」「どこが」を指させるか。**指せない文が1つでもあったら不合格。**

# 5. 語り手と専門家

| # | ルール | 根拠 |
|---|---|---|
| 5-1 | **広告と記事で語り手をずらしてよい。**揃えるのは**角度の言葉と機構の名前** | 競合は広告＝本人／記事＝専門家。機構名は両方で同じ |
| 5-2 | 視点の配分は**本人40%／家族40%／専門家20%**（競合15本の実測）。**一番長く回るのは本人**（平均60.8日） | — |
| 5-3 | **本人視点の広告には、専門家を登場人物として出す。**記事の書き手に先に会わせる | 長く回っている110日・85日の広告が両方これ |
| 5-4 | **専門家役に、その人が本当に知っていることだけ喋らせる** | 服のお直し屋に骨の機構を説明させかけた。**リフレームだけ渡して、機構は本人が調べる形**にした |

| 5-6 | **人を責めない。**責めるのは仕組みか訓練のほう | 110日の勝ち広告：「私のカイロプラクターは何も隠していませんでした。**ただ知らなかっただけ**です」 |

| 5-8 | **短文は指摘を7つ並べて、そのあと「3つ以上あてはまるなら」で採点させる** | 最初は3つで足りると書いていた。**120日稼働の実物は7つ並べて数えさせている。**問いを1つ投げて引用を貼っただけでは、感情が動かないまま記事へ飛ばすことになる |

# 6. 画像〔コース Phase 5〕

- 中核の問い：**この問題を抱えている人が、今スマホを掴んで自分の現実を記録するなら、何を撮るか**
- 3タイプのどれか1つ。混ぜない：**①見つめている物 ②誰も見ていない証拠 ③それと独りでいる瞬間**
- **当事者の視点で撮る。**観察者視点は「他人の問題」に見える
- **Redditテスト**：「またこれに対処してる」のキャプションで投稿して意味が通るか
- 禁止：解決策を見せる／きれいにする／文字を入れる／悲しみを演じる顔／ストック写真の構図

**失敗例**：鏡の中の女性を**横から見た画**にした＝観察者視点。**本人がスマホを構えて撮った画**に直した。

# 7. 書き終わったら必ず数える（目視で判断しない）

```bash
python3 - <<'PY'
import re
b=open('ad.md',encoding='utf-8').read().split("〔PR〕",1)[1].split("# 画像")[0]
n=len(re.sub(r'\s|---|\*|✘|→','',b))
s=[x for x in re.split(r'[。\n]',re.sub(r'\*|✘|→','',b)) if x.strip()]
L=[len(x.strip()) for x in s]
print('字数',n,'／文',len(L),'／平均',round(sum(L)/len(L),1),'／40字超',sum(1 for x in L if x>40))
print('あなた',b.count('あなた'),'／私',b.count('私'))
for w in ['商品名','価格','保証']: pass
PY
```

**失敗例**：字数も「あなた」の回数も、**測らずに書いて全部ずれていた**（5,100字と書いて実測2,577字）。

## 論理の検算（内容のチェックとは別に必ずやる）

**条件で競合を落とすときは、落とす理由が本当にその条件かを1つずつ確かめる。**

**失敗例**：姿勢ベルトを「1つ目（人に頼まなくていい）」で落としていた。**ベルトに予約は要らない。**
正しくは2つ目（毎回つける位置を合わせる）。

# 8. 納品の形

1. 上に**構築の表**。部品（variable）ごとに**誰の知識か**を書く（Mark／Justin／Konvert／コース／競合／うちの実測）
2. その下に**本文だけ**
3. 最後に**画像プロンプト**
4. **余計なことを書かない。**訂正の記録・メタ説明・前置き・言い訳を足さない
5. 報告は**結論と、本人がやることだけ**

**失敗例**：offer brief を直したときに「⚠️訂正」というメタ説明のブロックを足して、**それ自体を消させられた。**
