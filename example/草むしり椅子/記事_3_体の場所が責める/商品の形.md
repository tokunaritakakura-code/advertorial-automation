# 商品の形（らくらく草取りチェア・記事3）

読む人: この記事の画像を作る Claude と、画像を確かめる Claude。
読む時: 商品が写る画像を作る前と、作った1枚を確かめる時。
読まなくていい条件: 商品が写らない画像（人の顔・体の中の図）だけを作る時。

本物の形の見本: `商品の見本/`（Gardien の Garden Kneeler/Seat の商品写真。同じ形の 2way のガーデンニーラー。https://www.gardienproducts.com/products/garden-seat-kneeler ）。色だけうちの決め（下の表）に替える。

| # | 部分 | 形（作った1枚と1行ずつ合わせる） |
|---|---|---|
| 1 | 枠 | 深い緑（#2f5d3a）の丸いパイプ。左右に1本ずつ、逆U字の取っ手。取っ手の上の横の棒が、にぎる所 |
| 2 | 取っ手の高さ | 膝をつく向きで、地面から約55cm。膝をついた人の腰の少し下まで来る |
| 3 | 台 | 横長の長方形のクッション1枚（幅約60cm・奥行き約27cm・厚さ約4cm）。色は砂色（ベージュ）。角は少し丸い |
| 4 | 向き① 膝をつく | 台の上の面が地面から約12cm。取っ手が台の両はしから上へ立つ |
| 5 | 向き② 座る | 裏返すと、取っ手が脚になり、台が高さ24cmの座面になる。脚は左右に逆U字が2つ |
| 6 | 道具袋 | 深い緑の布の袋。片方の取っ手に掛ける。外にポケットが3つ |
| 7 | たたむ | 脚が内側にたためて、厚さ約10cmの板になる |
| 8 | 字・ロゴ | 商品に字やロゴは無い |

使ってはいけない形: 背もたれがある・車輪がある・台が丸い・取っ手が片方だけ・取っ手が台の面から30cmより短い・枠が銀色や黒。
