草むしりの後に、腰が伸びない？

先に「立ち上がり方」を疑ってください

こんにちは。整形外科専門医の三浦です。高齢の方の腰と膝を、18年診てきました。

庭の手入れは、大変です。本当に、大変です。

ある週は、1時間草を抜いても平気です。

ところが次の週には、立つ時に腰が伸びず、膝に手をついて少しずつしか起きられません。

多くの方は、まず「年のせい」と考えます。たしかに、年とともに腰の筋肉は細くなります。

でも、草むしりの後だけ立てなくなる方を診る時、私がまず見るのは「立ち上がり方」です。

しゃがんだ所から、腰と膝だけで体を持ち上げていないか。私はこれを「腰だけ立ち」と呼んでいます。

私の母も、畑で立てなくなった1人でした。

夕方、畝の間にしゃがんだまま、30分動けなかったそうです。

年のせいだけなら、草むしりの後だけ立てなくなるのは、おかしいのです。だから、年のせいは半分です。

ただ、立ち上がる瞬間に腰で何が起きているかを、見落とさないでください。

草むしりの後に立てなくなった方に、私が話すこと

立ち上がる時、体の重さを持ち上げる所は、たった1つに決まっています。腰です。

しゃがんでいる間、腰は深く曲がったまま止まっています。そこから立つ時、太ももが働く前に、腰が体の重さを引き上げます。

手をつく所が無ければ、重さを分ける先がありません。

1999年に、ドイツの研究チームが学術誌『Spine』に結果を載せました。45歳の男性1人の腰の骨の間（椎間板）に小さな計測器を入れ、暮らしの動きを1つずつ測った研究です。

まっすぐ立つ時を1とすると、前にかがむだけで約2.2。かがんだまま20kgを持ち上げると、約4.6でした。

かがんで持ち上げると、腰にかかる力は約4.6倍

つまり、こういうことです。しゃがんだ所から立つたび、腰は「重い物を持ち上げる」のと同じ仕事をしています。

草むしりは30分で、しゃがんでは立つを何十回もくり返します。夕方に腰が重く、次の朝に腰が抜けそうなのは、そのためだと私は見ています。

残念ながら、夏から秋は草がいちばん伸び、しゃがむ回数は増えていきます。

多くの対策は、しゃがむ時だけを楽にします。

×高さ20cmほどの園芸椅子 … 座るのは楽でも、立つ時に手で押す所が無く、結局腰だけで立つ
×膝当て … 膝は痛くなくても、立つ時はやはり腰だけで起きる
×腰のベルト … 締めても、持ち上げる重さは変わらない
×湿布 … 痛みはやわらいでも、次の草むしりで同じ所に重さが集まる
×業者に頼む … 1回1万〜3万円。庭はきれいでも、自分の庭ではなくなる

助けてくれると思っていた園芸椅子には、立つ時に手で押す所がありませんでした。座るのが楽なぶん、立つ時はやはり腰が1人で体を持ち上げていたのです。

立つ時の重さを、腰から別の所へ分ける。必要なのは、それだけです。

出典: Wilke HJ ほか（1999）Spine 24巻8号 755〜762ページ より要約

膝が痛くても使えますか

使えます。膝をつくのがつらい日は、台を裏返して高さ24cmの座面にして座ってください。座る向きで立つ時は、座面の両脇の枠に手をついて体を押し上げます。取っ手を押して立てるのは、膝をつく向きの時です。

体重が重くても大丈夫ですか

大丈夫です。耐荷重は120kgです。取っ手に体重をかけて押しても、ぐらつかない作りです。

腰の痛みが治る物ですか

いいえ。医療機器ではありません。立ち上がる時の重さを、腰から両腕に分けるための園芸の道具です。強い痛みやしびれがある方は、先に整形外科で診てもらってください。

雨に濡れても平気ですか

平気です。台は水をはじく素材で、拭けば乾きます。使った後は、たたんで軒下か物置に入れてください。

何台買えばいいですか

夫婦で庭に出るか、庭と菜園の2か所で使うなら2台セットです。2台目は半額なので、1台ずつ買うより2,990円安くなります。
